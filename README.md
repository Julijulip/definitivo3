# 🍔 FastFood Shop - React

FastFood Shop es una aplicación web tipo e-commerce inspirada en plataformas como Mercado Libre, enfocada en comida rápida. Está desarrollada con React y permite gestionar productos, carrito de compras y favoritos con una experiencia de usuario dinámica.

---

## 🚀 Funcionalidades

- 🧭 **Navbar con navegación completa**
  - Inicio
  - Artículos
  - Ofertas
  - Mi cuenta
  - Carrito
  - Favoritos

- 🍕 **Catálogo de productos**
  - Lista de comida rápida
  - Visualización de productos con imagen, nombre y precio

- 🛒 **Carrito de compras**
  - Agregar y eliminar productos
  - Vista del total acumulado
  - Gestión dinámica del estado

- ❤️ **Sistema de favoritos**
  - Agregar o quitar productos favoritos
  - Vista separada de productos guardados

- 🔥 **Página de ofertas**
  - Uso de `useState` para manejo dinámico de promociones
  - Productos destacados o con descuento

- 🔐 **Login de usuarios**
  - Validación de formulario
  - Simulación de autenticación
  - Control de acceso a ciertas vistas

- 🎨 **Interfaz moderna**
  - Diseño tipo marketplace
  - Estilos personalizados en CSS
  - Experiencia responsive (adaptable a móvil y escritorio)

---

## 🧰 Tecnologías utilizadas

- React.js ⚛️
- JavaScript (ES6+)
- CSS3
- React Router DOM

# 🍔 FastFood Shop - React

Proyecto de carrito de compras estilo Mercado Libre hecho en React.

## 🚀 Funcionalidades

- Navbar con navegación
- Listado de productos (comida rápida)
- Agregar al carrito
- Agregar a favoritos
- Página de ofertas con useState
- Login con validación
- Vista de carrito
- Vista de favoritos

## 📦 Instalación

```bash
npm install
npm run dev
